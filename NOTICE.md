## What comes from the original project

- The skill structure and directory layout
- The workflow: read the article → pick cognitive anchors → shot list → single-image generation → QA → delivery
- The reference file system (`style-dna`, `composition-patterns`, `prompt-template`, `qa-checklist`) and most of its wording
- The bundled example images in `examples/images/` and `tuotuo-illustrations/assets/examples/`, which were generated by Ian

## What has been changed in this derivative

- The recurring visual IP has been replaced: 小黑 has been removed and replaced with the author's own character 托托 (Tuotuo) and the optional companion cat mia.
- The annotation color system has been narrowed from red/orange/blue to black plus dark green only.
- Corresponding rewrites in `SKILL.md`, `agents/openai.yaml`, all reference files, `README.md` and `examples/prompts.md`.
