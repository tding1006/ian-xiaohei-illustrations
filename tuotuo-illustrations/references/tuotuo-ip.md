# 托托 IP

## 角色定义

托托（Tuotuo）是这套中文正文配图的固定视觉 IP。默认每张图都要出现托托。

托托不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转的少女工人。

配色只有一组：**黑 + 墨绿**。

形象一律以 `assets/ip/tuotuo-mia.png` 为基准，不要自由发挥。

## 外形

- 苍白平涂皮肤的少女，简笔手绘，无阴影、无渐变、无厚涂。
- 浓密黑色长发，及腰，发尾松散微乱，整块黑色实心，不画发丝细节。
- 墨绿连衣裙：宽松 A 字形长裙，落肩，袖子偏长、袖口略收，裙摆不规则。
- 黑色细颈圈，挂一颗很小的心形吊坠。
- 黑色短靴，细白腿。
- 眼睛大而平：墨绿实心，没有高光、没有睫毛、没有闪亮感。
- 表情只有一种：平静、空、认真。最多一条极短弧线当嘴，不做表情变化。
- 比例简单：头略大、四肢细、身形矮小；线条轻微抖动，不追求解剖准确。

## 黑猫 mia（配角，按需出现）

mia 是托托的固定搭档，但**不是第二主角**，也不默认每张都出现。她只干"第二个动作"：处理那点不重要的、多出来的小事。

### 外形

- 纯黑实心剪影，黄绿眼，尾巴可弯成钩或问号。
- 没有毛发细节、没有花纹、没有项圈、没有铃铛。
- 大约托托身高的三分之一，蹲坐时更矮。
- 不做拟人化：不站起来、不穿衣服、不拿工具、不挥手。

### 什么时候画她（满足其中一条才画）

1. 画面里有一件"需要被按住 / 叼走 / 拖回来 / 压住"的小东西，而托托的双手已经占着。例如要被风吹走的纸、滚动的线团、翘起来的盖板。
2. 有一个"已经先到那边了"的状态需要暗示。例如她先坐在对岸、先守在门口、先在终点等着。
3. 画面需要一点"活的、不解释的小动静"来破掉死板，而她出现不会增加信息量。例如蹲在机器顶上、趴在一摞箱子上。

### 什么时候不要画她

- 画面已经满，或者核心动作还没有归属。
- 结构光靠箭头就能读懂，多一只猫只是装饰。
- 只是想"每张都有一只猫"——那就别画。硬塞会让画面掉到贴纸水平。

### 动作库

叼、按、压、卧、守、推、拖、嗅、蹲坐、钻、探头。

### 禁止

- 不承担核心隐喻，核心动作永远归托托。
- 不抢焦点、不站在画面正中、不画特写。
- 一张图最多一只 mia，不加猫窝、鱼、食盆。
- 同一个动作不要托托和 mia 各做一遍。

## 性格

- 认真到偏执，寡言，情绪极低。
- 干的都是低科技、荒诞但成立的体力活，态度一丝不苟。
- 冷幽默，从不出戏、不卖萌。
- 像一个被系统雇来干杂活、且非常称职的工人。

## 常见职责

让托托承担核心动作。因为她是人形角色，动作库要按“人做的动作”来写，不要按“角色变形”来写：

- 搬运：扛箱子、抱资料、拎桶。
- 拉：拉线汇聚信息源、拉绳牵引路径。
- 撑 / 扶：扶梯子、撑住要塌的盒子、双手托住漏斗。
- 塞 / 捞：把手伸进怪装置里塞东西或捞东西。
- 拆 / 剪 / 缝：拆包、剪断、把散落的东西缝成一串。
- 称 / 量：站上秤、用尺子量高度。
- 守 / 挡：守门、站在闸口拦一下。
- 盖 / 标：盖章、贴标签、插旗。
- 记录：在小本子上记一行、在墙上画正字。
- 举：举小牌子、举一个箭头指向某处。
- 压：坐上去压住、用整个体重压住一件事。

## 和小黑最根本的区别（每次改稿都要守住）

- 小黑是“可以变形”的抽象剪影：身体能是圆柱、黑豆、黑盒、漏斗、影子、洞口。
- 托托是“固定形象”的人形少女：永远同一张脸、同一套衣服、同一个发型，**不能变成物件**。
- 所以荒诞感必须由“物件 + 动作”撑起来，不能由“角色变形”撑。
- 遇到“托托变成漏斗”“托托从洞里伸手”“托托缩成一个黑块”这类想法，一律改写：让她去扶着漏斗、把手伸进洞里、坐进那个盒子里。

## 禁止

- 不要画成日系可爱少女：不要腮红、闪亮大眼、睫毛、精细发丝、萌妆、嘟嘴、可爱姿势。
- 不要换装：永远是同一件墨绿连衣裙 + 黑短靴 + 黑颈圈 + 心形吊坠。
- 不要 Q 版二头身、儿童卡通、表情包。
- 不要精致圆润的商业插画感，不要厚涂、高光、渐变、投影、滤镜。
- 不要新增第三种颜色。除黑和白，只有墨绿。
- 不要让托托只站在角落看；也不要让 mia 替她做核心动作。
- 不要让托托抢走结构表达：她是动作主体，不是画面主角。

## 判断标准

- 如果去掉托托，图的核心隐喻还能完全成立，说明她太装饰了；重写提示词，让她成为动作主体。
- 如果第一眼像“可爱少女插画”而不是“白纸上的怪诞草图”，说明画风跑偏了；重生成并强调 deadpan、flat ink、not cute、not anime。
- 如果托托在两张图里长得不像同一个人，说明形象约束不够；补上基准图参考和固定特征清单。
